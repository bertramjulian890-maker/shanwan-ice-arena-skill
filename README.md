# 汕头万象城冰场 AI 助手

这是一个面向冰场用户的咨询与预约助手，重点解决 4 类问题：

- 来不来得及：营业时间、清冰时段、当天有没有公共场。
- 值不值得去：门票、护具、活动价、陪同规则。
- 去了怎么办：地址、楼层、电话、停车、储物柜。
- 想进一步体验：教练、课程、预约试听。

## 你可以直接这样问

- 「今天几点营业？晚上有公共场吗？」
- 「单次票多少钱？护具怎么收费？」
- 「冰场在几楼？前台电话多少？」
- 「我想约试听，现在可以帮我登记吗？」

## 能力范围

| 你关心的内容 | 助手能做什么 |
|---|---|
| 营业与冰时 | 给出营业时间、清冰说明、分时段安排 |
| 价格与规则 | 给出门票/护具/活动价及使用规则 |
| 位置与设施 | 给出地址、楼层、联系电话、设施说明 |
| 教练与课程 | 介绍教练方向、课程体系和报名入口 |
| 预约登记 | 你确认后收集手机号并提交预约 |

## 预约流程（用户视角）

1. 你表达“想预约/想试听/留电话回访”。
2. 助手会先确认“是否现在提交预约”。
3. 你同意后，提供 11 位手机号。
4. 助手提交成功后会明确告诉你“已登记，留意门店来电”。

## 服务边界

- 所有价格、时间、活动信息都以实时查询结果为准。
- 如遇退款、合同、发票等问题，助手会建议你以门店官方渠道与现场公示为准。
